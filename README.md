# Homnaro static website

This site is ready for GitHub Pages: it has no build step or server dependency.

1. Create a GitHub repository and upload every file in this folder.
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. GitHub will show the public website address once publishing is complete.

Keep `index.html`, `styles.css`, `script.js`, and `homnaro-logo.png` together in the repository root.
